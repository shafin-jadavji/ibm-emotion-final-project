# IBM Emotion Analysis Project

## Overview
This project is an AI-driven application that analyzes and interprets human emotions from text input. Using **Natural Language Processing (NLP)** techniques, it determines sentiment and emotional tone, making it useful for applications such as customer feedback analysis, mental health insights, and chatbot sentiment detection.

## Features
- **Emotion Detection**: Identifies emotions such as joy, sadness, anger, and more.
- **Text Processing**: Uses NLP techniques to clean and analyze input text.
- **API Integration**: Supports interaction with AI models for advanced sentiment analysis.
- **Scalability**: Designed for easy integration into chatbots, customer service platforms, and feedback systems.

## Technologies Used
- **Programming Language**: Python
- **Libraries**: NLTK, Transformers, OpenAI API
- **Frameworks**: Flask for API integration
- **Version Control**: Git & GitHub

## Installation
```bash
# Clone the repository
git clone https://github.com/shafin-jadavji/ibm-emotion-final-project.git

# Navigate to the project directory
cd ibm-emotion-final-project

# Install dependencies
pip install -r requirements.txt
```

## Usage
```bash
# Run the application
python app.py
```
After starting the application, send a text input to analyze emotions.
